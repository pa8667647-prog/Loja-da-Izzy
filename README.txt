BOM GAROTO — VERSÃO COM IMAGENS

1. Extraia o ZIP.
2. Abra a pasta no Visual Studio Code.
3. Abra index.html no navegador ou use a extensão Live Server.

ARQUIVOS:
- index.html: estrutura e textos
- style.css: visual e cores
- script.js: produtos, preços, filtros e carrinho
- images/: ilustrações de produtos de exemplo em SVG

COMO COLOCAR SUAS FOTOS:
1. Copie uma foto para a pasta images (ex.: camiseta-preta.jpg).
2. Abra script.js e localize o produto.
3. Altere o campo imagem para: imagem:"images/camiseta-preta.jpg"
4. Salve e atualize o navegador.

Pode usar JPG, PNG, WEBP ou SVG. As imagens atuais são ilustrações editáveis de demonstração, não fotos reais.
O carrinho é demonstrativo e não recebe pagamentos reais nem registra pedidos num servidor.
